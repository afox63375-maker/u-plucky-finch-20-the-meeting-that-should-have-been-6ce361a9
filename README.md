# The Meeting That Should Have Been an Email

One line, one meeting, zero emails sent. This entry turns the complaint
inside out: a team gathers to cut down on meetings and walks out with a
new recurring one on the calendar. The joke lands on its own — no setup,
no punchline telegraphed — because the absurdity is the whole meeting.

`main.py` (Python standard library only) writes the single joke line to
`/output/entry.txt` and refuses to write anything outside the 1–200
character limit.
